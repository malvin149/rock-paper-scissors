# Rock Paper Scissors 
A browser-based Rock Paper Scissors game built as part of The Odin Project Foundations curriculum. 

## How to Play

- Click Rock, Paper, Scissors to make your choice
- The compiter picks randomly 
- First to 5 points wins 
- Click Replay to start a new game 

## Built With 

- HTML 
- CSS 
- Javascript (DOM manipulation)
